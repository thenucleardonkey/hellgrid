# Hellgrid

A demon-wave shooter in a 3D grid maze, made with three.js in a single HTML file.

**Play:** https://thenucleardonkey.github.io/hellgrid/

WASD or arrows to move, Space or F to fire, R to reload, right mouse button or E to scope. Click the view for mouse look; Esc opens settings, where you can rebind keys. Pick a perk before every wave and survive eight waves.
